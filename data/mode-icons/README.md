# Mode icons (sources)

Drawn by the project author in Inkscape, released under CC0 1.0 with the rest of the project. One SVG per mode of the first page (R-MOD-1), with its tile family:

- `timer.svg`: Timer, normal (rounded square tile).
- `interval.svg`: Interval timer, normal.
- `time-attack.svg`: Time attack, normal.
- `workouts.svg`: Workouts, advanced (hexagon tile).
- `exercises.svg`: Exercises, advanced.
- `metronome.svg`: Metronome, advanced.
- `quick-start.svg`: Quick start, normal (placeholder).
- `dashboard.svg`: Dashboard, normal (placeholder).
- `auto-pace.svg`: Auto-pace, normal (placeholder).
- `manual-pace.svg`: Manual-pace, normal (placeholder).

These are the editable sources and are not installed. The app uses the PNG renders next to them (384 x 384 px), made by `tools/make-mode-icons.py`.
