# Exercise pictograms

67 single-colour pictograms (128 x 128 SVG, 256 x 256 PNG renders), one per exercise icon key of the starter library, plus `default`.
They are produced by `tools/make-exercise-icons.py` (CC0 1.0); the style rules are in the script header.
The SVG files use `currentColor` so the app can tint them with the exercise colour.
