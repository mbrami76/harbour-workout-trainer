# Muscle-group pictures

Nine pictures, one per muscle group of the exercise library: chest, back, shoulders, arms, core, glutes, quadriceps, hamstrings, calves. Each shows a neutral figure in the front or back view that fits the group, with the region highlighted. They were made for this project. The SVG files are the sources; the PNG files (400 x 960 px) are rendered from them and are what the app installs. `template.svg` shows the front and back figures with all nine groups in distinct colours and defines the regions the single pictures are cut from; it is not installed. `tools/make-muscle-groups.py` writes the SVG files.
